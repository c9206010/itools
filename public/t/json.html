常見的 JSON 語法錯誤

  • 最後一個元素後面多了逗號：[1, 2, 3,] 在 JavaScript 裡合法，但 JSON 不接受。
  • 用單引號：JSON 規定字串一定要用雙引號，{'a': 1} 是錯的。
  • 鍵沒有加引號：{a: 1} 要寫成 {"a": 1}。
  • 有註解：標準 JSON 不支援 // 或 /* */ 註解。
  • 結尾被截斷：從瀏覽器主控台複製時常常少了最後幾個括號。

常見問題

「轉成跳脫字串」什麼時候用？
當你要把一整段 JSON 當成字串塞進另一段程式碼或另一個 JSON 欄位裡的時候。它會把雙引號變成 \"、換行變成 \n，貼進去才不會把外層的語法弄壞。
中文會被轉成 \u 編碼嗎？
不會，這個工具輸出的中文維持原樣，可讀性比較好。JSON 標準兩種寫法都合法，多數程式讀取時沒有差別。
資料會外傳嗎？
不會。解析與排版都在你的瀏覽器執行，含有 API 金鑰或客戶資料的 JSON 貼進來也不會送出。
