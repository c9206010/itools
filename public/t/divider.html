〰️分隔線裝飾產生器

貼文太長想分段、想把重點框起來，這裡挑一條複製就好，不用自己一個一個符號慢慢打。

分隔線（點一下複製）
自訂符號
文字外框

貼上去對不齊怎麼辦

文字外框在等寬字型下才會整齊——每個字元寬度一樣，線條才對得上。程式編輯器、終端機、部分記事本是等寬的，但 IG、FB、LINE 用的都是比例字型，中文字比英文字母寬，框線很容易歪掉。

實務上的建議：分隔線在哪裡都很安全，因為它只有一行；文字外框則建議只放在部落格的程式碼區塊，或是純中文、每行字數相同的短句，歪掉的機率才低。

常見問題

為什麼有些符號顯示成方框？
代表那台裝置沒有收錄該符號的字型。製表符號（框線那類）與常見的星號、圓點相容性都很好；比較冷門的裝飾符號在舊手機上風險較高。要給不特定多數人看的內容，挑簡單的比較保險。
分隔線會影響貼文字數嗎？
會，每個符號都算一個字元。20 個字元的分隔線就吃掉 20 個額度，IG 貼文上限 2200 字元，放幾條沒問題，但別放太多。
可以用在部落格文章嗎？
可以，不過網頁有正規的做法——用 CSS 畫真正的分隔線，排版才會隨螢幕寬度自動調整。文字符號做的線在手機上可能會被硬生生截斷或換行。社群平台不能寫 CSS 才需要這種做法。
