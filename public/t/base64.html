🔐Base64 編碼解碼

文字轉 Base64、Base64 轉回文字，中文跟 Emoji 都不會變亂碼。也可以直接丟檔案進來轉。

把檔案轉成 Base64

選一個檔案就會轉成 Base64（含 data URI 前綴，可直接貼進 HTML 或 CSS）。大檔案會很長，建議 2MB 以下。

Base64 不是加密

這點很重要：Base64 只是把資料換一種表示方式，任何人拿到都能直接解回原文，完全沒有保密效果。它的用途是讓二進位資料（圖片、附件）能夠安全地通過只接受文字的管道，例如電子郵件、JSON、網址參數。密碼、金鑰、個資千萬不要只用 Base64 就當作保護。

為什麼編碼後會變長

Base64 用 4 個字元表示原本的 3 個位元組，所以編碼後的長度大約是原本的 1.33 倍。把圖片內嵌成 data URI 之前記得先評估，小圖示很划算，大圖片反而會讓網頁變肥。

常見問題

中文為什麼有些工具會轉出亂碼？
因為瀏覽器內建的 btoa 只吃單位元組字元，遇到中文會直接報錯或出錯。這個工具先把文字轉成 UTF-8 位元組再編碼，所以中文、日文、Emoji 都能正確來回轉換。
「網址安全格式」是什麼？
標準 Base64 會用到 + 和 /，這兩個字元在網址裡有特殊意義，直接放進 URL 會出問題。網址安全格式把它們換成 - 和 _，就可以安心放在網址或檔名裡。
檔案會上傳到伺服器嗎？
不會。檔案是用瀏覽器的 FileReader 在你自己的電腦上讀取與轉換的，完全沒有經過網路。
