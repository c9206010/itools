HEX、RGB、HSL 什麼時候用哪個

  • HEX（#e8562a）：最通用，設計軟體與 CSS 都認，適合存下來或跟別人溝通。
  • RGB（rgb(232, 86, 42)）：跟螢幕的紅綠藍三原色直接對應，要做透明度（rgba）時很方便。
  • HSL（hsl(14, 81%, 54%)）：色相、飽和度、亮度分開表示，要調出同色系的深淺變化時最好用——只要改亮度那個數字就好，不必重新配色。

對比度為什麼要檢查

文字跟背景的亮度差太小就看不清楚。無障礙設計的通用標準是：一般內文需要 4.5:1 以上，大字（18pt 以上或粗體 14pt 以上）需要 3:1 以上。上面的檢查會直接告訴你這個顏色配白字或黑字有沒有過關，做按鈕或標題底色時可以先確認一下。

常見問題

CMYK 的數值可以直接拿去印刷嗎？
不建議。這裡的 CMYK 是用最簡單的數學公式換算的，而實際印刷的色彩轉換要考慮紙張、油墨與色彩描述檔，同一組 CMYK 在不同印刷條件下差很多。要送印的話請以印刷廠指定的色彩設定為準，這裡的數值只能當參考。
支援哪些輸入格式？
三碼與六碼的 HEX（含帶不帶 # 都行）、八碼帶透明度的 HEX、rgb()、rgba()、hsl()、hsla()，還有 CSS 的標準顏色名稱例如 tomato、steelblue。
明暗階梯怎麼產生的？
把顏色轉成 HSL 之後，固定色相與飽和度，只改變亮度，從很亮到很暗均勻取 11 個階。這是設計系統裡建立色階最常見的做法，同一排顏色會自然屬於同一個色系。
