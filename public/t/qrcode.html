容錯等級要選哪一個

QR Code 本身帶有修復能力，即使部分髒污或破損還是掃得到，等級越高能容忍的損壞越多，但相對的圖案會變得更密，同樣尺寸下反而更難掃。

  • L / M：螢幕顯示或乾淨的印刷品，選這兩個就夠，圖案最清爽。
  • Q / H：要印在容易磨損的地方（貼紙、戶外看板），或是打算在中間疊一個 logo，選高一點。

Wi-Fi QR Code 怎麼用

選「Wi-Fi 連線資訊」填好網路名稱與密碼，產生的 QR Code 讓客人用手機相機掃一下就能直接連線，不用報密碼。iPhone 與 Android 的原生相機都支援。印出來貼在店裡或放在餐桌上很實用。

常見問題

掃不出來怎麼辦？
最常見的三個原因：一是內容太長導致圖案過密，二是前景色與背景色對比不夠（淺色底配深色點才掃得到，顏色反過來多數掃描器會失敗），三是列印尺寸太小。先把顏色改回黑白試試。
產生的 QR Code 會過期嗎？
不會。QR Code 是把內容直接編碼進圖案裡，不經過任何轉址服務，所以沒有到期問題，也不會有人統計掃描次數。缺點是產生之後就不能改內容了，網址若要更動，必須重新產生一張。
內容有長度上限嗎？
有，而且跟容錯等級有關。純數字最多可以放幾千個字，但中文很佔空間，實務上建議控制在一兩百字以內，太長會密到掃不動。長文章建議改放網址。
